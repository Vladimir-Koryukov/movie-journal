# Movie Journal: сценарий видео на 5–7 минут

Цель записи: показать запуск через `kubectl apply`, работающие Pod, увеличение числа реплик через `kubectl scale` и действия в интерфейсе приложения в Minikube. Установку программ и сборку образов завершите заранее по [инструкции запуска](README.md).

## До начала записи

1. Полностью пройдите инструкцию запуска, включая операции с фильмом. Убедитесь, что приложение работает на этом ноутбуке.
2. Оставьте Docker Desktop и Minikube включёнными. Образы backend, frontend и PostgreSQL должны уже находиться в кластере.
3. Подготовьте два окна PowerShell и браузер. В первом откройте `C:\Projects\movie-journal` (или свой корень проекта). Второе предназначено для port-forward.
4. Настройте запись всего экрана и микрофона, чтобы в ролик попали оба окна и браузер. Проверьте 10-секундную пробную запись; увеличьте шрифт терминала.
5. Остановите прежний port-forward через `Ctrl+C`.

Чтобы на записи показать запуск Pod, после репетиции остановите только нагрузки приложения следующими командами. Они сохраняют namespace, Services, настройки и PVC с данными. Выполняйте по блокам, проверяя успешное завершение ожиданий.

```powershell
kubectl config use-context minikube
kubectl scale -n movie-journal deployment/frontend deployment/backend --replicas=0
kubectl wait -n movie-journal --for=delete pod -l app=frontend --timeout=120s
kubectl wait -n movie-journal --for=delete pod -l app=backend --timeout=120s
```

Если Pod уже отсутствуют, ждать их удаления не нужно. Затем:

```powershell
kubectl delete job migrate -n movie-journal --ignore-not-found
kubectl scale -n movie-journal statefulset/db --replicas=0
kubectl wait -n movie-journal --for=delete pod/db-0 --timeout=120s
kubectl get pods,pvc -n movie-journal
```

В namespace приложения не должно остаться Pod; PVC `data-db-0` должен оставаться `Bound`. Не удаляйте namespace или PVC. На записи повторный `apply` вернёт по одной реплике из манифестов. Миграция на сохранённой базе проверит актуальность схемы — это ожидаемо.

Подготовка закончена. Очистите экран первого терминала командой `Clear-Host` и включите запись. Время ниже ориентировочное: сделайте одну репетицию, чтобы уложиться в 7 минут.

## 0:00–0:30 — представить приложение и кластер

Скажите: «Это Movie Journal: frontend на Nginx, backend на Spring Boot и PostgreSQL. Приложение разворачивается в одноузловом Minikube».

```powershell
kubectl config current-context
kubectl get nodes
```

Покажите контекст `minikube` и один узел `Ready`.

## 0:30–1:20 — запустить базу

```powershell
kubectl apply -f .\k8s\namespace.yml
kubectl apply -f .\k8s\config.yml
kubectl apply -f .\k8s\postgres.yml
kubectl rollout status -n movie-journal statefulset/db --timeout=180s
kubectl get pods,pvc -n movie-journal
```

Скажите: «Настройки передаются через ConfigMap и Secret. PostgreSQL работает в StatefulSet, данные находятся на постоянном томе». Покажите `db-0` — `1/1 Running` и PVC — `Bound`.

## 1:20–2:00 — выполнить миграцию

```powershell
kubectl apply -f .\k8s\migrate.yml
kubectl wait -n movie-journal --for=condition=Complete job/migrate --timeout=240s
kubectl get jobs -n movie-journal
```

Скажите: «Отдельный Job применяет миграции Flyway перед запуском backend. Он завершился успешно». На повторной демонстрации схема уже существует, поэтому новые изменения могут не понадобиться.

## 2:00–3:10 — запустить приложение и показать Pod

```powershell
kubectl apply -f .\k8s\backend.yml
kubectl rollout status -n movie-journal deployment/backend --timeout=240s
kubectl apply -f .\k8s\frontend-config.yml
kubectl apply -f .\k8s\frontend.yml
kubectl rollout status -n movie-journal deployment/frontend --timeout=180s
kubectl get pods,services -n movie-journal
```

Покажите три работающих Pod: db, backend, frontend. Pod миграции со статусом `Completed` — успешно выполненная задача.

Скажите: «Frontend передаёт API-запросы через Service backend на порт 8080. Backend подключается к базе через Service db на порт 5432».

## 3:10–4:00 — увеличить число реплик

```powershell
kubectl scale -n movie-journal deployment/backend --replicas=2
kubectl rollout status -n movie-journal deployment/backend --timeout=240s
kubectl get deployment backend -n movie-journal
kubectl get pods -n movie-journal -l app=backend -o wide
kubectl get endpointslices -n movie-journal -l kubernetes.io/service-name=backend -o wide
```

Скажите: «Количество реплик backend увеличено с одной до двух. Service имеет два адреса готовых Pod, обе реплики работают с общей базой». Покажите `2/2` у Deployment.

## 4:00–5:40 — показать интерфейс

Во втором PowerShell запустите:

```powershell
kubectl --context=minikube port-forward -n movie-journal service/frontend 18080:80 --address=127.0.0.1
```

Оставьте окно работающим и откройте [http://127.0.0.1:18080](http://127.0.0.1:18080).

1. Добавьте фильм «Демонстрация Kubernetes», год 2024, статус «Планирую посмотреть».
2. Нажмите «Редактировать», поменяйте статус на «Просмотрен», укажите оценку 9 и заметку «Работает в Minikube», сохраните.
3. Обновите страницу: запись осталась.
4. Переключите фильтр статуса, затем верните показ всех фильмов.
5. Удалите только что созданную демонстрационную запись и подтвердите удаление.

Скажите: «Интерфейс обращается к приложению в Kubernetes. Добавление, изменение и удаление записей работают».

## 5:40–6:10 — завершить

Вернитесь в первое окно PowerShell:

```powershell
kubectl get pods -n movie-journal
```

Покажите frontend, две реплики backend, PostgreSQL и завершённую миграцию. Скажите: «Показаны запуск манифестами, состояние Pod, масштабирование и работа интерфейса». Остановите запись.

Пересоздание Pod базы с проверкой сохранности записи уже есть в полной инструкции. Для обязательного сценария видео этот дополнительный эксперимент не нужен; оставьте его за кадром, если не укладываетесь по времени.

## Что проверить в готовом ролике

- Длительность не более 7 минут, видны команды и результат, слышно объяснение.
- Есть применение манифестов через `kubectl apply` и появление работающих Pod.
- Есть `kubectl get` с готовыми Pod приложения.
- Есть `kubectl scale` и результат `2/2` у backend.
- Есть несколько действий в браузере с приложением из Minikube.

Видео покрывает демонстрационную часть. Для сдачи также нужны архив исходников/манифестов и отдельный отчёт по Kubernetes с описанием абстракций и взаимодействия сервисов. Инструкция запуска не заменяет такой отчёт.
